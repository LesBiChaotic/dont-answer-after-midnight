# AFTERHOURS
> *Stay up. Stay in touch.*

**AFTERHOURS** is a mobile-first, nocturnal Progressive Web Application (PWA) and alternate reality experience. Designed exclusively for late-night communication, vintage web archiving, and quiet conversations.

---

## 🌙 Features

- **Private & Group Messaging**: 1:1 threads and multi-participant group chats with realistic backscroll, typing indicators, draft persistence in IndexedDB, audio waveform seekbars, and reaction trays.
- **11 Community Rooms**: Topic channels (`#night-owls`, `#old-internet`, `#urban-legends`, `#quiet-hours`, `#soundscapes`, `#book-club`, `#hardware-lab`, `#midnight-cafe`, `#creative-corner`, `#room-support`, `#room-feedback`) with moderator pins and guidelines.
- **Legacy Platform Archives (2001–2026)**: Explore 30 period-accurate historical logs across 5 communication eras (2001 Midnight BBS, 2004 Lantern IRC, 2008 Hushrooms, 2013 Nitewire, and 2018 Beta).
- **In-Universe Help Center (`/help`)**: 30 substantive documentation articles covering privacy, block partitions, search operators, quiet hours schedules, and PWA installation.
- **Local-First & Offline Ready**: Service worker caching and full IndexedDB storage for offline reading and background drafting.
- **Visual Design Master v1.0**: Midnight Plum (`#11101A`) canvas with ink-blue, electric periwinkle (`#8197FF`), lilac (`#B979FF`), apricot (`#F0A06D`), and teal (`#57C7C1`) accents. Strict 3-surface depth hierarchy.
- **Full Accessibility (a11y)**: Minimum 44px touch targets, `prefers-reduced-motion` support, screen reader ARIA labels, and complete keyboard navigation.

## 🚀 Quick Start

### Development
```bash
# Clone the repository
git clone https://github.com/<your-username>/afterhours.git
cd afterhours

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
```

---

## 📦 Progressive Web App (PWA) Installation

- **iOS (Safari)**: Tap the **Share** button in Safari and select **"Add to Home Screen"**.
- **Android (Chrome)**: Tap the menu dots and select **"Install App"** or **"Add to Home Screen"**.
- **Desktop**: Displays the mobile promotional frame with a 390×844 simulator and QR scan target.
